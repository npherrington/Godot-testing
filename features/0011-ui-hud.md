# UI & HUD

Create health display, turn indicator, and inventory screen.

## Acceptance criteria

1. Health bar display (0-100)
2. Turn indicator (player/enemy)
3. Inventory screen showing items
4. Status icons (poison, freeze)
5. Menu navigation system

## Out of scope

- Complex animations
- Sound effects for UI
- Accessibility features
- Customizable UI

## Notes

- Health bar top-left corner
- Turn indicator center-bottom
- Inventory screen accessible via key
- Status icons right side
- Pixel-style font for all text
