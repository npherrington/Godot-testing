# Monster Database

Create 10 monster types with unique behaviors and stats.

## Acceptance criteria

1. Monster database with 10 types
2. Each monster has unique sprite
3. Unique behavior for each type
4. Different health/damage stats
5. Enemies spawn with correct types

## Out of scope

- All 20 monster types
- Unique animations per type
- Special abilities beyond basic behavior
- Boss enemies

## Notes

- Include: Skeleton, Ghost, Goblin, Slime, Ogre
- Each should have distinct movement pattern
- Stats should follow monster type guidelines
- Sprint animations not required yet
