# Item System

Implement inventory framework and basic items.

## Acceptance criteria

1. Inventory system with 24 slots
2. Weapons with attack stat bonuses
3. Armor with defense stat bonuses
4. Consumable items (healing pots)
5. Item pickup from dungeon

## Out of scope

- Complex inventory management
- Item crafting
- Equipment slots beyond basic
- Item effects beyond stats

## Notes

- Inventory visible in UI
- Item stats affect combat
- Pickup range: adjacent tiles
- Basic items: sword, shield, health potion
