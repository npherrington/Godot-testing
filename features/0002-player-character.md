# Player Character System

Create the player character with sprite animation and grid-based movement.

## Acceptance criteria

1. Player character exists as a scene with sprite node
2. Sprite animation controller with idle and walk animations
3. Grid-based movement system (8-directional)
4. Basic collision detection with walls
5. Player starts in center of arena with health=100

## Out of scope

- Player attack/combat abilities
- Health system integration
- Enemy interaction
- Camera follow behavior

## Notes

- Player sprite size: 32x48 pixels
- Movement should snap to grid positions
- Use tile-based collision grid
- Initial health state should be visible in GameState
