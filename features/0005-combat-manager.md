# Combat Manager

Create turn system controller and action queue for combat.

## Acceptance criteria

1. Turn system controller manages player and enemy turns
2. Action queue processes combat actions in order
3. Status effect framework initialized
4. Turn indicator visible on screen
5. Combat logs show action results

## Out of scope

- Specific combat abilities beyond basic attack
- Complex status effects
- Turn timer or time limits
- Enemy behavior beyond turn order

## Notes

- Turn order: player first, then enemies
- Basic status effects: poison, freeze
- Combat logs appear in visible UI element
- Turn indicator updates automatically
